# Abgabe-Checkliste

Prüfen Sie vor der finalen Abgabe, ob alle Punkte erfüllt sind.

## Pflicht

- [ ] Spiel startet
- [ ] `requirements.txt` ist aktuell (`pip freeze > requirements.txt`)
- [ ] README.md ausgefüllt: Teamtabelle, Spielbeschreibung, Anleitung, God Mode
- [ ] God Mode / Cheat zum schnellen Durchspielen vorhanden
- [ ] Ausschließlich Python mit PyGame verwendet
- [ ] Alle Teammitglieder haben eigene Commits mit HAW-E-Mail
- [ ] GenAI-Nutzung in Commit-Messages gekennzeichnet

## OOP & Refactoring (ab Woche 6)

- [ ] Klassen in eigene Dateien in `src/` ausgelagert
- [ ] Sinnvolle Vererbungshierarchie vorhanden
- [ ] Kapselung: Keine unnötig öffentlichen Attribute
- [ ] Refactoring-Commits mit erklärenden Messages erkennbar

## Design Patterns (ab Woche 8)

- [ ] Mindestens 2 Design Patterns implementiert
- [ ] Patterns im README.md dokumentiert
- [ ] Pattern-Einführung als Refactoring-Commit sichtbar

## UML

- [ ] `uml/klassendiagramm.mmd` aktualisiert (finaler Stand)
- [ ] Diagramm spiegelt die tatsächliche Code-Struktur wider

## Bonus

- [ ] Unit Tests vorhanden
- [ ] Besonders kreative Spielidee
- [ ] Mehr als 2 Design Patterns
- [ ] Herausragend lesbarer Code
